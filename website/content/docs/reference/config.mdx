# Configuration Reference

Complete reference for all configuration parameters in ProteinProcessIO.

## Pretreatment Parameters

### Machine Configuration

| Parameter | Type | Range | Default | Unit | Description |
|-----------|------|-------|---------|------|-------------|
| `belt_width` | float | 0.5-1.5 | 0.9 | m | Conveyor belt width |
| `belt_speed` | float | 0.01-0.10 | 0.05 | m/s | Belt linear velocity |
| `belt_length` | float | 1.0-5.0 | 3.0 | m | Treatment zone length |
| `rf_frequency` | enum | 13.56, 27.12 | 27.12 | MHz | RF operating frequency |
| `rf_power` | float | 0-15 | 10 | kW | Applied RF power |
| `electrode_gap` | float | 0.05-0.15 | 0.08 | m | Gap between electrodes |

### Material Properties

| Parameter | Type | Range | Default | Unit | Description |
|-----------|------|-------|---------|------|-------------|
| `dielectric_constant` | float | 2-10 | 4.5 | - | Real permittivity (ε') |
| `loss_factor` | float | 0.1-3 | 0.8 | - | Imaginary permittivity (ε'') |
| `specific_heat` | float | 1500-3000 | 2100 | J/kg·K | Heat capacity |
| `thermal_conductivity` | float | 0.05-0.5 | 0.15 | W/m·K | Thermal conductivity |
| `bulk_density` | float | 600-1000 | 780 | kg/m³ | Bulk density |

### Process Parameters

| Parameter | Type | Range | Default | Unit | Description |
|-----------|------|-------|---------|------|-------------|
| `initial_moisture` | float | 0.05-0.20 | 0.14 | wb | Initial moisture (wet basis) |
| `target_moisture` | float | 0.05-0.15 | 0.10 | wb | Target outlet moisture |
| `initial_temperature` | float | 10-40 | 25 | °C | Feed temperature |
| `max_temperature` | float | 50-90 | 65 | °C | Temperature limit |
| `feed_rate` | float | 10-500 | 100 | kg/hr | Mass flow rate |

### Simulation Settings

| Parameter | Type | Options | Default | Description |
|-----------|------|---------|---------|-------------|
| `resolution` | enum | low, medium, high | medium | Spatial grid resolution |

## Configuration Files

### User Preferences

Location: `~/.proteinprocessio/preferences.json`

```json
{
  "ui": {
    "theme": "dark",
    "language": "en",
    "show_tips": true
  },
  "simulation": {
    "default_resolution": "medium",
    "auto_save_interval": 300
  },
  "export": {
    "default_format": "csv",
    "include_metadata": true
  }
}
```

### Default Configurations

Location: `~/.proteinprocessio/defaults/`

Store your preferred starting configurations here. They appear in **File > New from Template**.

## Validation Rules

### Automatic Validation

The system validates:

- Parameter ranges (min/max values)
- Type correctness
- Physical consistency (e.g., gap > bed depth)
- Cross-parameter compatibility

### Warning Levels

| Level | Behavior |
|-------|----------|
| Info | Displayed, no action |
| Warning | Displayed, requires acknowledgment |
| Error | Blocks execution until fixed |

## API Reference

For programmatic configuration:

```python
from proteinprocessio import Config

# Load configuration
config = Config.load("project.acproj")

# Modify parameters
config.milling.rotor_rpm = 4000
config.milling.screen_aperture = 1.0

# Validate
errors = config.validate()
if not errors:
    config.save("modified.acproj")
```
