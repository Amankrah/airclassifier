# Keyboard Shortcuts

Speed up your workflow with these keyboard shortcuts. All shortcuts work across the application unless noted.

## General Shortcuts

### File Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New project |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save project |
| `Ctrl+Shift+S` | Save as |
| `Ctrl+W` | Close project |
| `Ctrl+Q` | Quit application |

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+C` | Copy |
| `Ctrl+V` | Paste |

## Customizing Shortcuts

### Viewing Current Bindings

1. Go to **Edit > Preferences > Keyboard**
2. Search for any command
3. See current shortcut

### Changing Shortcuts

1. Find command in preferences
2. Click on shortcut field
3. Press new key combination
4. Click **Apply**

<Callout type="warning">
Some shortcuts are system-reserved and cannot be changed. Conflicting shortcuts will show a warning.
</Callout>

### Resetting Defaults

To restore default shortcuts:

1. Go to **Edit > Preferences > Keyboard**
2. Click **Reset to Defaults**
3. Confirm

## Platform Differences

### macOS

Replace `Ctrl` with `Cmd` for most shortcuts:
- `Cmd+S` instead of `Ctrl+S`
- `Cmd+Q` instead of `Ctrl+Q`

### Linux

Some desktop environments may capture shortcuts. Check:
- System shortcuts in Settings
- Window manager bindings
