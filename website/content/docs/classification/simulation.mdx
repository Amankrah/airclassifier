# Running Classification Simulations

Execute and monitor air classification simulations to optimize particle separation.

## Starting a Simulation

### Pre-run Verification

Ensure your configuration is complete:

- ✓ All enabled stages configured
- ✓ Feed properties set (or transferred from milling)
- ✓ Air flow settings validated
- ✓ No configuration warnings

### Launch Methods

| Method | Shortcut |
|--------|----------|
| Run button | Click **Run Simulation** |
| Keyboard | `F5` |
| Menu | **Simulation > Run** |

### Color Coding

Particles are colored by:

**Size Mode (default)**:
| Color | Size |
|-------|------|
| Blue | < 20 μm |
| Green | 20-50 μm |
| Yellow | 50-100 μm |
| Orange | 100-200 μm |
| Red | > 200 μm |

**Fate Mode** (toggle with `F`):
| Color | Destination |
|-------|-------------|
| Green | Fines outlet |
| Red | Coarse outlet |
| Yellow | In transit |

### View Controls

| Control | Action |
|---------|--------|
| Mouse drag | Rotate view |
| Scroll wheel | Zoom |
| `1` - `4` | View presets (front, side, top, 3D) |
| `R` | Reset camera |
| `F` | Toggle color mode |
| `T` | Toggle trajectory trails |

## Convergence Monitoring

### Steady State Detection

The simulation monitors:
- Mass balance closure
- PSD stability at outlets
- Pressure drop stability

Convergence is reached when:
- Mass balance error < 1%
- PSD change < 0.5% per second
- Outlet flows stable

### Early Termination

If results converge early:
- System notifies "Steady state reached"
- Option to continue or stop
- Results available immediately

<Callout type="info">
Most classification simulations reach steady state within 30 seconds of simulated time. Extended runs improve statistics but don't change average results.
</Callout>

## Batch Operations

### Parameter Sweep

Explore optimal operating conditions:

1. **Select variable**: RPM, air flow, or cut point
2. **Define range**: e.g., 3000-5000 RPM
3. **Set steps**: e.g., 5 runs
4. **Run sweep**: Automated execution

### Optimization

Automatic optimization for targets:

```yaml
Optimization Target:
  maximize: protein_concentration
  constraint: yield > 25%

Variables:
  wheel_rpm: [3000, 6000]
  air_flow: [300, 600]
```

## Troubleshooting

### Simulation Stalls

| Symptom | Cause | Solution |
|---------|-------|----------|
| No progress | Particles stuck | Check wall settings |
| Oscillating | Unstable flow | Reduce time step |
| Memory full | Too many particles | Reduce count |

### Unrealistic Results

| Issue | Possible Cause | Check |
|-------|----------------|-------|
| No separation | Air velocity too low | Increase flow |
| All to fines | Cut point too high | Increase RPM |
| All to coarse | Cut point too low | Decrease RPM |
| Poor sharpness | Turbulence issues | Check geometry |
