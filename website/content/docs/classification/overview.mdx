# Air Classification System

The air classification module simulates particle separation by size and density using aerodynamic forces. This is the final stage for producing protein-enriched and starch-enriched fractions from milled pulse flour.

## Separation Principle

Air classification exploits differences in particle behavior under combined drag and gravitational or centrifugal forces:

- **Small/light particles**: Carried by air flow
- **Large/heavy particles**: Settle against air flow

### Key Forces

```
                    ↑ Drag (Fd)
                    │
              ○     │
              │     │
    ←────────●──────────→ Centrifugal (Fc)
              │
              │
              ↓ Gravity (Fg)
```

The balance determines particle trajectory:
- Fd > Fg → Particle rises (fines fraction)
- Fd < Fg → Particle falls (coarse fraction)
- Fc > Fd → Particle rejected (in wheel classifiers)

## System Components

The simulation models a multi-stage classification system:

```
                    ┌─────────────┐

                    │  Aspirator  │
                    └──────┬──────┘
                           │

            ↓                             ↓
     ┌────────────┐               ┌────────────┐
     │   Zigzag   │               │   Coarse   │

     └──────┬─────┘               └────────────┘
            │                            │
     ┌──────┴──────┐                     ↓
     ↓             ↓               Coarse Outlet

```

### Venturi Aspirator

First-stage rough separation:

| Parameter | Typical Value |
|-----------|---------------|
| Air velocity | 10-15 m/s |
| Channel width | 0.1-0.2 m |
| Separation | Removes hulls, large fragments |

### Zigzag Classifier

Multi-stage counter-current separator:

| Parameter | Typical Value |
|-----------|---------------|
| Number of stages | 6-12 |
| Channel width | 0.05-0.1 m |
| Air velocity | 2-5 m/s |
| Channel angle | 120° |

Particles bounce between stages, with fines carried up and coarse falling down.

### Wheel Classifier

Precision separator using centrifugal force:

| Parameter | Typical Value |
|-----------|---------------|
| Wheel diameter | 0.15-0.3 m |
| Wheel RPM | 2000-6000 |
| Air flow | 200-800 m³/hr |
| Cut point | 10-50 μm |

<Callout type="info">
The wheel classifier provides the sharpest cut, essential for high-purity protein concentration.
</Callout>

### Cyclones

Particle collection and air recirculation:

| Type | Purpose |
|------|---------|
| Fines cyclone | Collect fine product (protein) |
| Coarse cyclone | Collect coarse reject |
| Air return | Recirculate clean air |

## Physical Principles

### Stokes' Law

For small particles (Re < 1):

```python
# Terminal settling velocity
v_t = (ρ_p - ρ_f) × g × d² / (18 × μ)

# Where:
# ρ_p = particle density
# ρ_f = fluid density
# g = gravitational acceleration
# d = particle diameter
# μ = fluid viscosity
```

### Centrifugal Classification

In the wheel classifier:

```python
# Separation criterion
d_cut = √(18 × μ × Q) / (π × ω² × r × (ρ_p - ρ_f) × L)

# Where:
# Q = volumetric flow rate
# ω = angular velocity
# r = wheel radius
# L = wheel length
```

### Particle Properties

Separation depends on:
- **Size**: Primary factor
- **Density**: Starch (1.5) vs protein (1.3) g/cm³
- **Shape**: Sphericity affects drag
- **Moisture**: Affects stickiness

## Applications

### Standard Protein Concentration

Produce 50% protein concentrate:
- Single-pass classification
- D50 cut around 20 μm
- Yield: 30-35% of feed

### High-Purity Protein

Produce 65%+ protein isolate:
- Multiple classification passes
- Tighter cut points
- Yield: 15-20% of feed

### Starch Recovery

Maximize starch fraction purity:
- Focus on coarse collection
- Minimize fine carryover
- Yield: 50-60% of feed as >90% starch

<Callout type="warning">
Multiple passes increase purity but reduce yield. Optimize based on your product specifications and economics.
</Callout>
