# Mass Balance Tracking

Mass balance is fundamental to process engineering. ProteinProcessIO tracks mass flow through the entire pipeline to ensure accuracy and identify losses.

## Mass Balance Principle

**Conservation of Mass:**
```
Mass In = Mass Out + Accumulation + Losses
```

For steady-state operation (Accumulation = 0):
```
Mass In = Mass Out + Losses
```

## Troubleshooting

### Balance Doesn't Close

If closure is not 100%:

| Gap | Likely Cause | Check |
|-----|--------------|-------|
| < 1% | Rounding errors | Normal, acceptable |
| 1-5% | Minor losses | Dust, spillage settings |
| > 5% | Configuration issue | Stage parameters |
| > 10% | Error | Re-run simulation |

### Finding Missing Mass

1. **Check each stage separately**
   - Run pretreatment alone, verify closure
   - Run milling with fixed input, verify closure
   - Run classification with fixed input, verify closure

2. **Look for hidden streams**
   - Dust collection systems
   - Sampling points
   - Spillage/bypass

3. **Verify transfer settings**
   - Transfer efficiency factors
   - Loss assumptions

### Improving Closure

```yaml
Settings for Accurate Mass Balance:
  simulation:
    particle_count: 20000  # Higher for better statistics
    track_all_losses: true

  reporting:
    decimal_places: 4      # More precision
    include_trace_losses: true
```

## Best Practices

### For Accurate Mass Balance

1. **Use consistent basis**: Wet or dry, don't mix
2. **Include all streams**: Don't ignore minor losses
3. **Validate intermediate points**: Check between stages
4. **Compare to reality**: Benchmark against plant data

### For Reporting

1. **State basis clearly**: "All flows on wet basis"
2. **Report uncertainties**: ±2% typical
3. **Include timestamps**: When simulation was run
4. **Note assumptions**: Transfer efficiencies, etc.
