# Particle Size Distribution Analysis

Understanding and interpreting PSD results is essential for optimizing your milling process.

## PSD Fundamentals

### What is PSD?

Particle Size Distribution describes the range of particle sizes in your milled product. It's typically represented as:

- **Cumulative curve**: % passing vs. size
- **Frequency curve**: % in each size bin

### Key Parameters

| Parameter | Symbol | Description |
|-----------|--------|-------------|
| D10 | d₁₀ | 10% of mass is finer |
| D50 | d₅₀ | Median size (50% finer) |
| D90 | d₉₀ | 90% of mass is finer |
| Span | (D90-D10)/D50 | Width of distribution |
| Mode | dₘₒdₑ | Most common size |

## Reading PSD Charts

### Cumulative Curve

The default view shows cumulative mass percent:

- **Steep curve**: Narrow distribution (uniform)
- **Gradual curve**: Wide distribution (varied)
- **S-shape**: Normal distribution

### Frequency Distribution

- Identifying peaks (modes)

### Fraction Analysis

Define size ranges to quantify fractions:

| Fraction | Size Range | Typical % | Characteristic |
|----------|------------|-----------|----------------|
| Ultra-fine | &lt; 20 μm | 3-8% | Airborne dust |
| Fine | 20-50 μm | 10-20% | Protein-rich |
| Medium-fine | 50-100 μm | 15-25% | Mixed |
| Medium | 100-200 μm | 20-30% | Bulk flour |
| Coarse | 200-500 μm | 15-25% | Starch-rich |
| Oversize | > 500 μm | 5-15% | Fragments |

### Rosin-Rammler Fit

The simulation fits data to the Rosin-Rammler equation:

```
R(d) = 100 × exp[-(d/d')ⁿ]

Where:
R(d) = cumulative % retained
d' = characteristic size (D63.2)
n = uniformity index (spread)
```

| n Value | Distribution |
|---------|--------------|
| &lt; 1 | Very wide |
| 1-2 | Wide |
| 2-3 | Moderate |
| > 3 | Narrow |

## Interpreting Results

### For Protein Fractionation

Optimal PSD for air classification:

| Metric | Target | Why |
|--------|--------|-----|
| D50 | 100-150 μm | Optimal separation range |
| Fines (&lt;50 μm) | > 20% | Protein fraction mass |
| Span | 2-3 | Broad enough for separation |

<Callout type="success">
A bimodal PSD with peaks at ~40 μm and ~200 μm indicates good protein/starch liberation - ideal for fractionation.
</Callout>

### For Whole Flour

| Metric | Target | Why |
|--------|--------|-----|
| D50 | 150-250 μm | Baking functionality |
| Fines (&lt;50 μm) | 10-15% | Avoid dustiness |
| Oversize (&gt;500 μm) | &lt; 5% | Smooth texture |

### Warning Signs

| PSD Pattern | Indicates | Action |
|-------------|-----------|--------|
| Very narrow | Over-grinding | Reduce RPM or time |
| Excessive fines | Too dry or brittle | Check moisture |
| Bimodal with gap | Incomplete grinding | Increase RPM |
| High oversize | Screen too large | Reduce aperture |

## Optimization

### Adjusting Parameters

To shift D50 lower (finer):
1. Increase rotor RPM
2. Decrease screen aperture
3. Reduce feed rate
4. Reduce feed moisture

To shift D50 higher (coarser):
1. Decrease rotor RPM
2. Increase screen aperture
3. Increase feed rate
4. Increase feed moisture

### Narrowing Distribution

To reduce span:
- Use staged grinding (coarse then fine)
- Pre-classify feed
- Optimize moisture

### Increasing Fines

To generate more fines (&lt;50 μm):
- Increase tip speed
- Use smaller screen aperture
- Reduce feed moisture to 8-9%
