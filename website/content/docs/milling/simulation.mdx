# Running Milling Simulations

Execute and monitor hammer mill simulations in ProteinProcessIO.

## Starting a Simulation

### Pre-run Checklist

Before running, verify:

- ✓ Mill parameters configured
- ✓ Feed properties set (or transferred from pretreatment)
- ✓ Simulation settings appropriate for your needs
- ✓ No warnings in the status panel

### Launch Controls

| Method | Action |
|--------|--------|
| Button | Click **Run Simulation** |
| Keyboard | Press `F5` |
| Menu | Simulation > Run |

## Simulation Modes

### Standard Mode

```yaml
Standard:
  Particles: 5000
  Time Step: 0.001 s
  Duration: 10 s
  Runtime: ~30 seconds
```

### Quick Preview

For parameter exploration:

```yaml
Quick Preview:
  Particles: 1000
  Time Step: 0.005 s
  Duration: 5 s
  Runtime: ~5 seconds
```

Enable: **Simulation > Quick Preview**

### Extended Run

For statistical accuracy:

```yaml
Extended:
  Particles: 20000
  Time Step: 0.001 s
  Duration: 30 s
  Runtime: ~5 minutes
```

Enable: **Simulation > Extended Run**

<Callout type="info">
Extended runs produce smoother PSD curves and more accurate throughput predictions, but require more computation time.
</Callout>

## GPU Acceleration

### Enabling GPU

If a compatible GPU is available:

1. Go to **Settings > Performance**
2. Enable **Use GPU Acceleration**
3. Select your GPU device
4. Restart simulation

### Performance Comparison

| Mode | 5000 particles | 20000 particles |
|------|---------------|-----------------|
| CPU only | 30s | 8 min |
| GPU (RTX 3060) | 5s | 45s |
| GPU (RTX 4090) | 2s | 15s |

## Batch Processing

### Parameter Sweep

Explore parameter space:

1. Open **Simulation > Parameter Sweep**
2. Select variable (e.g., RPM)
3. Define range: 2500 to 4500, 5 steps
4. Click **Run Sweep**

Results are compiled into a comparison table.

### Sensitivity Analysis

Identify important parameters:

1. Open **Analysis > Sensitivity**
2. Select output metric (e.g., D50)
3. Click **Run Analysis**

The system varies each parameter ±10% and reports sensitivity.

## Interrupting Simulations

### Pause

- Press `Space` to pause
- Review current state
- Press `Space` to resume

### Stop

- Press `Escape` to stop gracefully
- Results up to that point are saved
- Can export partial results

### Emergency Stop

If the simulation is unresponsive:

- Press `Ctrl+Shift+Escape`
- Force terminates
- Recovery may be incomplete

## Troubleshooting

### Simulation Stalls

| Symptom | Cause | Solution |
|---------|-------|----------|
| Progress stuck | Numerical instability | Reduce time step |
| Memory full | Too many particles | Reduce particle count |
| GPU error | Driver issue | Update drivers or use CPU |

### Unrealistic Results

| Issue | Possible Cause | Check |
|-------|----------------|-------|
| No breakage | Feed too soft | Material properties |
| All fines | Feed too brittle | Moisture setting |
| Low throughput | Screen clogged | Screen parameters |
| High temperature | Excessive power | RPM setting |
